# Convite · Maria Clara 20 anos

Arquivos: `index.html` (convite), `admin.html` (painel), pasta `api/` (salva as respostas).

## Publicar
1. Suba todos os arquivos (mantendo a pasta `api`) num repositório do GitHub.
2. Na Vercel: Add New > Project > importe o repositório > Deploy.
3. No projeto da Vercel: Storage > Create Database > **Upstash (Redis)** > Connect to Project.
4. Settings > Environment Variables: crie `ADMIN_KEY` com a senha que você quiser para o painel.
5. Deployments > Redeploy.

Convite: `https://SEU-SITE.vercel.app/`  ·  Painel: `https://SEU-SITE.vercel.app/admin.html`
